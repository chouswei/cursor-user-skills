# Kids photo coloring page (artist method)

Printable black-outline coloring sheet a child will recognize. Artist observation from photos -- not filters.

## Pipeline
1. Character sketch + [likeness-face-sketch](../likeness-face-sketch/SKILL.md) until recognition passes.
2. Assemble full page only after face approval; keep user's favorite composition if named.
3. Final kids page: open B/W outlines, large crayon regions (screentone only if asked on the final).
4. Letter/A4 PNG (+ PDF). Title as hollow letters when used.

## Page craft
Face is the focal point; readable silhouette; props simplified; character belongs in the scene.

## Fail
Named landmark wrong -> back to [likeness-face-sketch](../likeness-face-sketch/SKILL.md) / [localized-feature-study](../localized-feature-study/SKILL.md) -- don't redesign the whole page to "fix" a face.
