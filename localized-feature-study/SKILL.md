# Localized feature study

Zero in on one struggling facial/body part with a practice sheet from photo refs (comic tutorial habit: arms, legs, eyes, brows, ears...).

## When
User (or recognition fail) names a part: eyebrows, eyes, nose, mouth, ear, hand, etc.

## Steps
1. Gather 3-8 close refs of that feature on the same person (or subject).
2. Fill a sheet with small studies: front / 3/4 / profile if relevant.
3. Start with simple forms; then clean contours; optional light screentone.
4. Note the rule you learned (e.g. "brows thin, low, nearly straight").
5. Re-apply onto the main head/figure construction.

## Do not
Redraw the entire character from scratch for every small fail -- isolate the part.
