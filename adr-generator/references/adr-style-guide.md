# ADR Style Guide

## Tone and Style

- Be concise and factual.
- Use active voice where possible.
- Avoid jargon unless it is domain-specific and well-known.
- Clearly separate facts from opinions.

## Required Sections

Every ADR must contain:
1. Context
2. Decision
3. Alternatives Considered
4. Consequences

## Numbering

Use sequential numbering (ADR-001, ADR-002, ...). Update the filename and title accordingly.

## Status

Use one of: Proposed, Accepted, Superseded, Deprecated.

## Linking

Link to related ADRs, issues, or PRs in the References section.
