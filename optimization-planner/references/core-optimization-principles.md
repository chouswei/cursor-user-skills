# Core optimization principles library (token-optimized)

## Core rules

- Clearly state the objective function (maximize or minimize).
- List all hard and soft constraints.
- Identify decision variables and their domains.
- Find feasible solutions first, then optimize.
- Use sensitivity analysis to understand robustness.
- Consider trade-offs when multiple objectives exist.

## Common optimization patterns

- Linear programming (LP)
- Integer programming
- Greedy heuristics for knapsack/scheduling
- Constraint satisfaction problems (CSP)
