# Core control theory principles library (token-optimized)

## Core rules

- Use feedback loops to correct deviations from desired state.
- Ensure system stability; avoid oscillations or instability.
- Apply PID control (proportional, integral, derivative) for responsive correction.
- Observability: can you measure the state accurately?
- Controllability: can you influence the state effectively?
- Consider time delays and their impact on control.

## Common patterns

- Negative feedback for stability
- Feedforward control for anticipation
- State-space representation
- Stability analysis
