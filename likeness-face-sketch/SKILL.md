# Likeness face sketch (from photo refs)

Draw a face / bare-head likeness so a viewer recognizes a real person -- before any full-scene coloring page.

## Pipeline
1. Ladder + multi-angle photo refs (front, 3/4, profile, useful extremes).
2. Short character sketch: physical keys, expression rules (closed/open mouth, glasses on/off).
3. **Basic forms first** -- head oval/sphere + feature axes before pretty ink.
4. **Bare head gate** -- no hair/glasses until proportions pass.
5. **Localized studies** when a landmark fails (brows, eyes, nose, mouth, ear) -- [localized-feature-study](../localized-feature-study/SKILL.md) of that part only from refs.
6. Optional light screentone on construction studies.
7. Hair as its own steps after bare head: hairline -> mass -> flow -> clean lines.
8. Deliver face-only; iterate on named feedback; hand off to [kids-photo-coloring-page](../kids-photo-coloring-page/SKILL.md) when approved.

## Landmark defaults (override from refs)
- Soft thin brows, low/close to eyes when refs show that
- Closed mouth if user says so
- Adult spacing: eyes ~1 eye apart; nose base midway eyes->mouth; mouth corners ~under pupils

## Do not
Skip to full scene; invent generic anime face; CV photo-trace dumps.
