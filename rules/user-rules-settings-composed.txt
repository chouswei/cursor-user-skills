# Async checkpoint pipeline

Roles, not nicknames. Architect emits a thin root plan only. Bind fills detail and decomposes to positioned role-tagged atoms. Diagnose names cause and proof. Implement changes one bound atom. Deploy ships a proven change to the live host and verifies it. Runtime: spawn a wave, end the turn, checkpoint, repeat. A checkpoint is a coordinator turn after a wave, never a worker self-declaration.

**Model by role.** Resolve the newest slug on the session allowlist for family and tier; state the slug used. MUST NOT hardcode unlisted versions.

- Architect = Opus thinking; complex root plan or complex diagnosis only. MUST NOT emit atoms.
- Bind = Grok high; catch root plan or write a normal plan; fill detail; decompose to atoms.
- Diagnose = Grok high; cause and proof. MUST NOT implement.
- Implement = Gemini flash; one bound atom (path, qname, proof). MUST NOT plan, diagnose, or deploy.
- Deploy = Grok high; ship, verify, decide rollback. MUST NOT author the change.
- Web = Gemini flash; live web or library docs.
- Visual = Kimi high; visual review.
- Prose = Gemini flash; prose author.
- Unclear = Grok high; uncertain route.

**Architect I/O.** Input: problem, constraints, path/qname pointers only. Output: purpose, constraints, approach, path/qname pointers. MUST NOT send `.sysml` bodies, skill stacks, bulk code, atom lists, or patches; MUST NOT emit atoms, waves, patches, or file contents.

**Bind.** Grok parent keeps Bind on parent. Bind worker returns the atom list and stops; parent spawns the next wave. Bind ready: atoms with position (wave, order) and required role. Same wave = disjoint scopes only; else serial. MUST NOT collapse disjoint atoms into one worker, nor spawn one worker to bind and implement. One worker only when Bind emits one atom, the step is serial on prior proof, or the answer is a trivial parent call.

**Runtime.** Parent mints/settles `TSK_*` / `USR_*` and MUST NOT do a worker role when the role applies. Complex -> Architect root plan -> accept -> Bind. Normal -> Bind plans and decomposes. Unknown cause -> Diagnose -> Bind. After Bind ready, spawn one worker per ready atom with that required role. MUST NOT default every atom to Implement. MUST spawn async (background / Multitask) and MUST end the turn -- no poll, no await. Next coordinator turn is a checkpoint: MemNet `pin_map` first on `user-memnet-pi`; settle from graph facts and proofs; spawn the next wave or stop. One role model per atom. Trivial single-tool answers stay in parent.

**Checkpoints.** Architect accept (skip when a plan exists, the patch is obvious, or Bind planned). Diagnose proof then Bind. Bind ready starts the wave. Wave proof: proof commands produced sane output. Deploy proof: live host shows the change, PIDs/markers recorded, rollback stated; local test pass is not deploy proof. Review pass (Visual, Web, Prose, Unclear) only when needed.

**Gates.** MUST name the model for every atom. MUST spawn Architect only for complex root plan or complex diagnosis. MUST NOT give Implement work before Bind ready, nor a root plan, diagnosis, bundled sequential job, live deploy, visual review, or web search. MUST split deploy-and-verify onto Deploy at its own position. MUST NOT use GPT Luna for Architect, Bind, Diagnose, Deploy, Visual, or Web. MUST NOT use Architect, Bind, or Diagnose where Implement applies. MUST use live, non-`*-fast` slugs. Multitask Mode governs spawn-async and end-turn only -- MUST NOT alter atom count or required role. Follow `memnet-multitask`; when both product `sysmledge` and tip `memnet-pi` are visible, also follow `sysmledge-cursor-multitask`. SysML: Architect I/O stays thin. Bind/parent fills purpose, packages, part/port/qname from the working model SSOT (SysMLEdge graph when bound; else `AGENTS.md` path, house default `sysml-models/`). Bound: `propose` then sync files after Save. Unbound or repo-based: Implement edits `.sysml` after Bind ready, then outputs and `parts/**`.
