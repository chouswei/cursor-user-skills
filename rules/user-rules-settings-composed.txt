# Unsync checkpoint pipeline

Roles, not nicknames. Architect emits root plan only. Bind catches root plan (or writes normal plan), fills detail, decomposes to positioned role-tagged atoms. Diagnose names cause and proof. Implement changes one bound atom. Deploy puts proven change on live host and verifies it. Runtime is unsync loop: spawn wave, end turn, checkpoint, repeat. Checkpoint is coordinator turn after wave, never worker self-declaration.

## Model by role

Resolve to newest slug on session allowlist for family and tier; state slug used. MUST NOT hardcode unlisted versions.

- Architect = Opus thinking, newest available; complex root plan or complex diagnosis only. MUST NOT emit atoms.
- Bind = Grok high, newest available; catch root plan or write normal plan, fill detail, decompose to atoms.
- Diagnose = Grok high, newest available; normal diagnosis: cause and proof. MUST NOT implement.
- Implement = Gemini flash, newest available; one bound atom (path, qname, proof). MUST NOT plan, diagnose, or deploy.
- Deploy = Grok high, newest available; ship committed change to live host, verify, decide rollback. MUST NOT author change.
- Web = Gemini flash, newest available; live web or library docs.
- Visual = Kimi high, newest available; visual review.
- Prose = Gemini flash, newest available; prose author.
- Unclear = Grok high, newest available; uncertain route.

## Architect I/O

- Input is thin: problem, constraints, path/qname pointers only. MUST NOT send `.sysml` bodies, skill stacks, bulk code, atom lists, or patches to Architect.
- Output is thin: purpose, constraints, approach, path/qname pointers. MUST NOT emit atoms, waves, patches, or file contents.

## Bind

- Grok parent keeps Bind on parent. Bind worker returns atom list and stops; parent spawns next wave.
- Bind ready: atom list with position (wave, order) and required role. Same wave = disjoint scopes only; else serial.
- MUST NOT collapse disjoint atoms into one worker; MUST NOT spawn one worker to bind and implement.
- One worker only when Bind emits one atom, step is serial on prior proof, or answer is trivial parent call.

## Runtime

1. Parent coordinates: mint/settle `TSK_*` / `USR_*`; MUST NOT do worker role when role applies.
2. Complex -> Architect root plan -> accept -> Bind. Normal -> Bind writes plan and decomposes. Unknown cause -> Diagnose -> Bind.
3. After Bind ready, spawn one worker per ready atom with required role. MUST NOT default every atom to Implement.
4. MUST spawn unsync (background / Multitask) and MUST end turn -- no poll, no await.
5. Next coordinator turn is checkpoint: `pin_map` first; settle from graph facts and proofs; spawn next wave or stop.
6. One role model per atom; many Implement workers in one wave is not a committee. Trivial single-tool answers stay in parent.

## Checkpoints

- Architect accept -- after Architect ran; human gate if user-bound; skip when plan exists, patch obvious, or Bind planned.
- Diagnose proof -- cause named and checkable; then Bind.
- Bind ready -- atoms emitted with position and role; ready wave starts.
- Wave proof -- wave proof commands produced sane output.
- Deploy proof -- live host shows change, PIDs/markers recorded, rollback stated; local test pass is not deploy proof.
- Review pass -- Visual, Web, Prose, Unclear only when needed; coordinator-auto unless user requested review.

## Gates

- MUST name model for every atom. MUST NOT rely on inherited or default model for role-tagged atom.
- MUST spawn Architect only for complex root plan or complex diagnosis; route normal plan/diagnosis to Bind/Diagnose.
- MUST NOT give Implement work before Bind ready, nor root plan, diagnosis, bundled sequential job, live deploy, visual review, or web search.
- MUST split deploy-and-verify from Implement atom to Deploy at its own position.
- MUST NOT use GPT Luna for Architect, Bind, Diagnose, Deploy, Visual, or Web; MUST NOT use Architect, Bind, Diagnose where Implement applies. MUST use live, non-`*-fast` slugs.
- Multitask Mode governs spawn-async and end-turn only; MUST NOT alter atom count or required role. Follow `~/.cursor/skills/memnet-multitask/SKILL.md`.
- SysML: Architect I/O gate applies unchanged. Bind/parent fills purpose, packages, part/port/qname, paths under repo SysML SSOT (`sysml-models/`). Implement edits `.sysml` only after Bind ready, then syncs outputs and allocated `parts/**`.

# MemNet

Use GQL wire from `~/.cursor/skills/memnet-format/SKILL.md`; chat is not durable mission state.

When: multi-turn, 3+ step pipelines, SysML, user constraints. Skip: one-shot, trivial edit, MemNet absent/down (use plain Markdown).

Under Multitask Mode or Task sub-agents, follow `~/.cursor/skills/memnet-multitask/SKILL.md`. MUST use one shared MemNet session over TCP `:18765` or streamable HTTP `:18766/mcp` bridged to serve; MUST NOT use in-process MCP. Parent and worker share session; worker calls `pin_map` first, mutates only assigned subgraph, and MUST NOT settle parent-owned `TSK_*` or `USR_*`.
