# Incentive Alignment Review Checklist

## Core Principles
- Skin in the game: Do decision makers bear the downside?
- Principal-agent problems: Are incentives aligned between parties?
- Second-order effects: What unintended behaviors does this incentivize?
- Long-term vs short-term alignment.
- Hidden incentives and gaming the system.

## Review Questions
- [ ] Does this create misaligned incentives?
- [ ] Are there ways to game or exploit the system?
- [ ] Do rewards match the desired outcomes and time horizon?
- [ ] Is there sufficient skin in the game for key actors?
- [ ] What are the second and third order effects?
- [ ] Does it encourage cooperation or competition appropriately?

## Common Failure Modes
- Short-termism
- Metric gaming
- Adverse selection
- Moral hazard
- Perverse incentives
