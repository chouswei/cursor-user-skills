# Academic report style guide

## Voice and tone

- Use **formal, precise** academic English (or match the user’s language if they specify).
- Prefer **third person** and passive voice where conventional for methods (e.g. “Samples were analyzed…”).
- Use **hedging** for claims not backed by user-supplied evidence: “may suggest,” “appears to,” “is consistent with.”
- **Do not** fabricate statistics, citations, or study outcomes. Use placeholders or ask the user.

## Structure

- Default skeleton follows **IMRaD** where applicable: Introduction, Methods, Results, Discussion, Conclusion.
- **Review-style** papers: emphasize synthesis, thematic paragraphs, and gap analysis; Methods may be shortened or labeled “Search strategy.”
- **Thesis chapters** may include a short “Chapter roadmap” after the introduction paragraph.
- Keep **parallel headings** (same grammatical form within a level).

## Citations and references

- If sources are not provided, use **consistent placeholders**: `[Author, Year]` in text and a **References** section with entries like `[Author, Year] Full citation to be added.`
- If the user names a style (APA, IEEE, Chicago, Vancouver), follow that style **only for formatting patterns** you are confident about; otherwise note “Format per [style]” and use placeholders.
- Do not invent DOIs, page numbers, or journal volumes.

## Figures and tables

- Describe needed figures/tables in prose or as **Markdown table stubs** with `[Table N: caption]` / `[Figure N: description]` when data are absent.

## Terminology

- Define acronyms at first use: “Principal component analysis (PCA)…”
- Avoid colloquialisms, unsubstantiated superlatives (“amazing,” “clearly proves”).
