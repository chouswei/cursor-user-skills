# Meeting Notes Style Guide

## Structure

Every set of meeting notes must include:
- Date and attendees
- Agenda or topics discussed
- Key decisions
- Action items with owners and due dates
- Next steps

## Tone

- Objective and factual
- Use bullet points for readability
- Clearly mark action items
- Use consistent formatting for tables

## Action Items

Always format action items in a table with columns: Item, Owner, Due Date.

## Clarity

- Use clear, concise language
- Define acronyms on first use if needed
- Highlight decisions in a dedicated section
