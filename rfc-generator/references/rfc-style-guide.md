# RFC Style Guide

## Tone and Style

- Be clear, concise, and professional.
- Use active voice where appropriate.
- Define terms on first use if they are not widely known.
- Separate concerns: motivation, proposal, risks.

## Required Sections

Every RFC must contain:
1. Abstract
2. Motivation
3. Proposed Solution
4. Alternatives Considered
5. Implementation Plan
6. Risks and Mitigations

## Status Values

Use one of: Draft, Under Review, Accepted, Rejected, Implemented.

## Numbering

Use sequential numbering (RFC-001, RFC-002, ...).

## Linking

Include a References section with links to related work.
